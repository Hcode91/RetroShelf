# Ziperto metadata fixtures

Retrieved from Ziperto's public WordPress API on 2026-11-07:

- `/wp-json/wp/v2/posts?categories=3534&per_page=2&page=1` and `page=2`, restricted to id/link/title/excerpt/content/modified fields.
- `ziperto-detail.json` is the first listing's metadata from page 1.

`ziperto-page1.json` and `ziperto-page2.json` retain short descriptive metadata, original article/image URLs and the source information block. Unrelated instructions, ads and download-host links are omitted. No game binaries or images are bundled. Metadata and linked artwork are attributed to Ziperto and the respective publishers; no open license is asserted. Original source: https://www.ziperto.com/nintendo-switch-nsp/.
