A patch for The Dark Queen Of Mortholme to run on the PlayStation Vita.

The Dark Queen Of Mortholme is a game where you play as the Dark Queen - the most powerful being of your entire universe. Your lair is breached by an aspiring hero - a pitiful thing, easily crushed.

Except they keep coming back.

A 20 minute anti-game about an unconventional relationship and the capacity for change.

Installation edit

Requirements:

  • libshacccg.suprx
  • Your own copy of the game (purchase from Steam)

Prepare the game files:

  • Clone or download the PSVita patch repository.
  • Locate The Dark Queen Of Mortholme.exe in the downloaded game folder.
  • Place it inside the patch repository folder.
  • Using Python 3, execute the following command or double click it to execute it: python pck_patch_gui.py
  • Set up the following paths and press "Apply Patch":
    • Original (.pak/.exe): The Dark Queen Of Mortholme.exe
    • Patch Folder: The-Dark-Queen-Of-Mortholme-psvita/patch
    • Output .pak: game.pak
    • VPK Template: The-Dark-Queen-Of-Mortholme-psvita/vpk_template
    • Output .vpk: game.vpk
    • With Build VPK after repack enabled.

You now have two options to install it:

  • Install via VPK - Copy the generated game.vpk to your Vita and install it using VitaShell.
  • If you've downloaded the game on VitaDB - Place the game.pck file in ux0:app/MORT00001/.
